# Mantenimiento

Cosas que sirven para publicar o mantener este repositorio.
**Nada de acá hace falta para usar el skill**: si llegaste buscando cómo
procesar un export de WhatsApp, volvé al [README](../README.md).

## `crear-repo.sh`

Crea el repositorio público y sube solo los archivos del skill. Lo usó el autor
una vez, al publicarlo. Necesita [`gh`](https://cli.github.com) autenticado, y
se niega a correr si la carpeta tiene algo que no sea del skill.
